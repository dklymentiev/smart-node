# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them by email to the project maintainer. Include:

- A description of the issue and its potential impact.
- Steps to reproduce, including affected version.
- Any proof-of-concept code, if applicable.

You should receive an acknowledgement within 72 hours. We aim to provide a status update within seven days.

## Supported versions

Until v1.0, only the current `main` branch receives security fixes.

## Coordinated disclosure

Once a fix is available we will publish a release and a security advisory through GitHub. Reporters who follow coordinated disclosure will be credited unless they prefer otherwise.
