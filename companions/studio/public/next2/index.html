Built from the node's event feed (sn_core.events) and the planner status log. Agent work = runs of its events with gaps up to 5 minutes; each run is split across the tasks it mentions (planner call path or a four-digit number in the message text). The task supplies its project and objective. Emergent = tasks without a project, work without a task, and small projects. Other agent tools write no events, and money is not accounted for.
