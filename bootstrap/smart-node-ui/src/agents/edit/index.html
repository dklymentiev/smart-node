settings
access & permissions

Where this agent may read and write, and what it must never do. Filesystem lists are enforced on the node by OS ACL/sudoers; the panel stores them and renders them into agent.yaml. Forbidden behavior is an honor-system list injected into the prompt. The agent's own directory (/srv/agents/<slug>/, with logs/ output/ state/) is always its working dir and writable.

tools

What this agent can use, by where it comes from. The switch says whether the model is offered a server or a tool on each request; the size is what it adds to every request. Switches save at once and apply from the agent's next process start (after 15 minutes without work, or a new session). R, W and D are the agent's grants, saved with Save configuration.
