Secrets

Every credential of the node in one encrypted store: the gateway's provider keys (gateway/<provider>-key) and the integrations agents and companions use (replicate.api_key). Each row says where a secret is wired in, which agents may read it, who set it and who read it last. An agent refused a read appears under Requests, where one click grants it · values are never displayed or returned to the browser.
