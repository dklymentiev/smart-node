# Upgrade to 1.14.0

Follow [the update runbook](../runbook-update.md). Back up the node's databases, configuration and agent
directories; confirm the starting release is 1.13.4.

## Before you start

The end-user app is now called Studio inside as well as outside: the component that was `office` is
`studio`, and no compatibility with the old name is kept. An update does **not** move a node installed
as `office`. Do the move below by hand first, or reinstall the node.

## Move a node installed as office (by hand, once)

On the node, as root:

```sh
systemctl disable --now smart-node-office.service
rm -f  /etc/systemd/system/smart-node-office.service
rm -rf /etc/systemd/system/smart-node-office.service.d
systemctl daemon-reload
mv /var/log/smart-node/office /var/log/smart-node/studio
rm -f /etc/smart-node/traefik/dynamic/70-office.yml /etc/smart-node/office-brin.env \
      /etc/smart-node/manifests/office.manifest.json /etc/smart-node/companions.d/office.json \
      /var/lib/smart-node/stages/office.state
sed -i 's/smart-node-office/smart-node-studio/g' /etc/smart-node/traefik/dynamic/71-office-internal.yml 2>/dev/null \
  && mv /etc/smart-node/traefik/dynamic/71-office-internal.yml /etc/smart-node/traefik/dynamic/71-studio-internal.yml
cp -n /opt/smart-node/office/public/avatars/custom/* /var/lib/smart-node/agents/avatars/custom/ 2>/dev/null
rm -rf /opt/smart-node/office
userdel smart-node-office
```

Then run the update. The installer lays down `studio` (`/opt/smart-node/studio`, the
`smart-node-studio` service and user, `70-studio.yml`) as on a new node.

## What changes shape on the node

- `office.<domain>` no longer redirects to `studio.<domain>`; links to the old name stop working.
- Stored keys are renamed: `studio_user` in message metadata and the desk API (`office_user` before),
  mesh sources `studio`, `studio-upload`, `studio-gdrive`, `studio-chat`, session reason
  `studio_manual_clean`. Rows written before keep the old keys; old Studio chats may show no name for
  the person on earlier messages.
- A browser's unsent drafts were kept under `sn-office-drafts`; they are not carried over.
- The voice backend reads `SN_STUDIO_URL` (`SN_OFFICE_URL` before); the voice installer writes it.
