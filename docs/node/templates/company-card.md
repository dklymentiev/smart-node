# Business profile

**What this is.** This profile is what the node knows about your business. It is a document,
not a form: you can read it, correct it, and every change is kept. Everything the node
does is built from this profile -- how it introduces you, what it answers, what it may
decide on its own, and whom it calls when something goes wrong. Change the profile and the
node changes with it.

**How it grows.** The profile is filled in stages, not in one sitting. Each stage switches
something on, and you may stop at any stage: the node is never "half-configured", it is
configured exactly as far as you have told it. New sections open when real work runs into
a gap (a lead arrives from a city we never discussed, someone asks for a price that was
never set), not on a schedule.

**Rules of this document**

- "We do not know yet" is a real answer. Write it down. It tells the node exactly where
  it is blind, and it is where the next question comes from.
- An empty section blocks nothing. The node keeps working with whatever it already has.
- A section that switches nothing on is a note, not part of the profile.
- Sections that are not listed here can be added. This profile has no fixed shape: a
  distillery grows batches and a tasting room, a salon grows stylists and slots, a shop
  grows stock. Name a new section in your own words, not in ours.

## Branches

Branches are added when work demands them, one branch per gap, and never in advance. Each
branch is its own page, named in the business's own words.

What a branch typically is, depending on the answer to block 3:

- work arrives as requests -> how a request becomes a job, what it costs, who does it
- work is a booked slot -> the calendar, who can be booked, what happens on a no-show
- work is a sale from stock -> what is on the shelf, what it costs, who restocks it
- work is a production batch -> batches, timing, what has to be reported and to whom
- work is a subscription -> what people sign up to, what makes them leave

**Money is a branch, not part of the base.** It is real for every business, but it is
premature at stage 0: the node is not selling anything yet. It is born the moment a
customer says yes and asks where to pay.
